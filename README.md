# Patrick Ankomah — Developer Portfolio

A responsive personal portfolio presenting my work as a full-stack web developer.

The website introduces my background, technical capabilities and selected projects through detailed case studies and links to live deployments.

## Featured Projects

### HomeStride Services

A full-stack home-services booking and job-management platform with separate customer, administrator and technician experiences.

- Node.js and Express API
- PostgreSQL database
- JWT authentication and role authorization
- Skill-based technician assignment
- Request status tracking
- Cloudflare and Render deployment

### Cape Breeze Boutique Hotel

A responsive hospitality landing page inspired by Cape Coast, Ghana.

- Responsive navigation
- Room and amenities presentation
- Destination and testimonial content
- Formspree enquiry integration
- Cloudflare deployment and analytics
- Uptime monitoring

### ApexStone Construction

A responsive multi-page construction company website.

- Five connected pages
- Service enquiry preselection
- Filterable project gallery
- Expandable FAQs
- Contact-form validation
- GitHub Pages deployment
