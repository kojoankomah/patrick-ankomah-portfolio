# Patrick Ankomah Developer Portfolio

A responsive personal portfolio presenting my work as a full-stack web developer.

The website introduces my background, technical capabilities and selected projects through detailed case studies and links to live deployments.

## Live Website

[View the portfolio](https://patrick-ankomah-portfolio.pages.dev/)

## Featured Projects

### HomeStride Services

A full-stack home-services booking and job-management platform with separate customer, administrator and technician experiences.

* Node.js and Express REST API
* PostgreSQL database
* JWT authentication and role-based authorization
* Skill-based technician assignment
* Service-request status tracking
* Responsive role-specific dashboards
* Cloudflare Pages and Render deployment

[View live project](https://homestride-services.pages.dev/) | [Read case study](projects/homestride-services.html)

### Cape Breeze Boutique Hotel

A responsive hospitality landing page inspired by Cape Coast, Ghana.

* Responsive navigation
* Room and amenities presentation
* Destination and testimonial content
* Formspree enquiry integration
* Cloudflare deployment and analytics
* Uptime monitoring

[View live project](https://hotel-landing-page.patrickankomah4.workers.dev/) | [Read case study](projects/hotel-landing-page.html)

### ApexStone Construction

A responsive multi-page website created for a fictional construction company.

* Five connected pages
* Service enquiry preselection
* Filterable project gallery
* Expandable frequently asked questions
* Contact-form validation
* GitHub Pages deployment

[View live project](https://kojoankomah.github.io/construction-company-website/) | [Read case study](projects/apexstone-construction.html)

## Run Locally

No build process or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/kojoankomah/patrick-ankomah-portfolio.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` with the Live Server extension.

## Deployment

The portfolio is deployed through Cloudflare Pages and connected to the repository’s `main` branch. New commits pushed to `main` are deployed automatically.
